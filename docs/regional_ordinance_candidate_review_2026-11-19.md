# 2024 자치법규 연혁 후보와 행정코드 연결 결과

작성일: 2026-11-19

최신 실자료 확인: 2026-11-20 (Asia/Seoul)

## 수집 범위

국가법령정보센터 자치법규 목록 API에 `nw=2`(연혁), 자치법규명 검색, 시행일 범위 `20240101~20241231`을 지정했습니다. 검색어는 재활용, 분리수거, 폐기물, 자원순환, 생활폐기물, 재활용가능자원입니다. 최신 실행에서 전체 12페이지를 받아 후보 659개 버전(고유 자치법규 ID 592개, 기관명 219개)을 확보했습니다. 목록에 표시된 시행일은 모두 2024년입니다. 유형은 조례 561개, 규칙 98개입니다. 자치법규 본문 JSON은 후보 중 **60건**을 추가로 받았습니다.

검색은 제목 키워드에 의존하며 **시행일이 2024년인 연혁 버전의 검색**입니다. 2023년 이전부터 계속 유효한 조례나 현재도 현행인 버전까지 포함한 완전한 2024 법령 목록이 아닙니다. 시행일 하나로 연중 적용기간·폐지일·개정 전후 적용관계를 정하지 않습니다. 본문 60건은 수집 목록의 앞부분이며 대표 표본으로 설계한 것이 아닙니다. 법령 후보로 수집된 사실만으로 해당 정책의 실제 시행·대상·운영을 확인했다고 보지 않습니다.

## 2024 행정코드 대조

법제처 응답의 기관명 전체 문자열을 2024년 12월 MOIS 행정코드와 정확히 대조했습니다.

| 대조 상태 | 후보 버전 | 처리 |
|---|---:|---|
| 2024 폐기물 통계단위와 정확히 연결 | 523 | 2024 시군구 코드와 교차표에 기록 |
| 시도 단위 기관명 | 63 | 시군구 전체 노출로 간주하지 않음 |
| 2024 행정코드 목록에서 기관명 미매칭 | 73 | 지역을 추정하지 않고 미매칭으로 보존 |
| 행정코드에 연결됐지만 폐기물 통계단위가 아닌 코드 | 0 | 별도 독립 통계단위 없음 |

미매칭 73건은 32개 기관명에 해당합니다. 그중 일부는 2024 MOIS 목록에 없는 기관명(예: `전남광주통합특별시 ...`, `인천광역시 제물포구`)이고 일부는 교육청 기관입니다. 이 명칭을 2024년 통계지역으로 자동 환산하지 않았습니다. 각 정책이 과거 어느 권역에 적용됐는지 판단하려면 법제처 연혁·개정 조문·공식 과거 기관코드 등 추가 근거가 필요합니다.

입력에 기준월·연도가 있으면 2024년 12월·2024년인지 확인합니다. 혼합된 기준월, 모호한 시도명–코드 관계, 같은 코드의 상충하는 지역 식별자는 거부합니다. 같은 기관명에 서로 다른 코드가 있으면 추정으로 선택하지 않습니다.

## 본문 버전과 조문 근거

| 확인 항목 | 최신 결과 |
|---|---:|
| 본문 ID·일련번호·제목·기관·공포일·시행일 대조 | 60개 버전 |
| 조문·부칙·개정문·제개정이유의 텍스트 항목 | 1,031행 |
| 재활용·분리배출·수집 등 지정 단어가 언급된 항목 | 549행 |
| 텍스트 근거가 있고 통계단위 코드에 정확히 연결된 시군구 | 26개 |
| 실제 운영정책·성과의 검증 결합 | 0행 |

1,031행은 법령 수나 독립된 정책 수가 아닙니다. 반환된 `조내용`, `부칙내용`, `개정문내용`, `제개정이유내용`의 문자열마다 한 행을 기록합니다. 텍스트·조문번호·조제목·JSON Pointer·원문 SHA-256·버전 일련번호(MST)를 함께 보존하므로 수집한 원문 위치로 돌아가 대조할 수 있습니다. 날짜나 기관 메타데이터가 부족하거나 MST 없이 ID만 있는 경우는 버전 검토 대상으로 남깁니다.

목록과 본문에서 제목의 중점 문자가 `·`와 `ㆍ`로 달리 표기된 사례 9건은 제목 비교에만 중점·공백·NFC 정규화를 적용했습니다. 원문은 바꾸지 않으며 지역명에 유사 문자열 매칭을 적용하지 않습니다. 재질·수거방식 키워드도 단순한 언급 단서입니다. 예를 들어 법규의 `폐지`를 종이 재질로 자동 분류하지 않습니다.

공개 원문 링크는 API 인증값이 필요한 DRF 주소 대신 `ordinSeq=MST`인 법령정보센터 열람 화면에 연결합니다. 예: [달서구 재활용센터 설치·운영 조례의 수집 버전](https://www.law.go.kr/LSW/ordinInfoP.do?ordinSeq=1862925). 인증값을 제거한 API 주소는 별도 `api_source_url`로 남깁니다.

앱의 지역 연구 메뉴에서 법령명·기관·조문을 검색하고 해당 버전의 원문 링크와 근거 CSV를 열 수 있습니다. 시도·시군구 보고서에도 조문 근거 CSV가 연결됩니다.

## 현재 입력과 원문 재검증

법령 연결은 후보 CSV, 목록·본문 원문, API manifest, 12월 행정코드와 폐기물 통계단위의 논리적 로스터, 교차표·조문 CSV를 지문으로 연결합니다. 원문 누락·변경, 다른 후보 입력, 잘못된 기준월, 산출물 변경 또는 집계값 불일치가 있으면 현재 검증 수치는 0으로 표시하고 과거 수치와 구분합니다. 목록·본문 캐시도 파일 존재·해시·문서 신원을 다시 확인한 뒤 재사용합니다.

`--check-only`는 수집·파일 수정 없이 연결을 확인하며 성공은 종료코드 0, 실패는 2입니다. 이 검증은 입력·근거의 일관성 확인이며 법규의 정확한 적용기간이나 정책 효과를 증명하지 않습니다.

## 현재 결합 상태

행정코드 교차표는 **자치법규 후보와 통계지역을 연결한 탐색용 자료**입니다. 실제 운영 증거에 기반한 정책 후보는 아직 0건이며, 정책-성과 검증 결합도 0행입니다. 조례 제목·연혁·본문은 법률상 제도 근거를 보여주지만 2024년 사업 예산 집행, 운영 여부, 대상 범위(시군구 전체인지 일부 공동주택인지), 실제 수거방식이나 처리실적을 보증하지 않습니다.

정책별로 실제 시행계획·실적·계약·수거량 제출자료에서 시행일, 운영주체, 대상지역·주택유형, 재질, 수거·처리 단계와 집계범위를 확인해야 합니다. 원표 결과와 같은 측정대상·연도·행정단위가 확인된 뒤에만 검증 결합을 시도합니다. 따라서 현재 단계에서는 523개 코드 일치 후보를 정책효과·노출자료로 취급하지 않습니다.

- 법제처 검색 후보: `data/processed/regional_2024/policy_ordinance_candidates.csv`
- 2024 행정코드 교차표: `data/processed/regional_2024/policy_ordinance_geography_crosswalk.csv`

- 집계 결과: `data/processed/regional_2024/policy_ordinance_candidate_summary.json`
- 재현: `scripts/collect_law_ordinances.py --limit-pages 30 --details 60`, `scripts/link_law_ordinances.py`, `scripts/link_law_ordinances.py --check-only`
