# RPL 통계분석 중심 개편 결과

기준일: 2026-11-16(한국시간). 프로젝트 명칭을 **RPL | 분리배출 정책 통계분석 및 시각화**로 통일하고 실제 통계 분석을 기본 화면으로 구성했다.

**가시적 결과:** [독립 분석 9개의 대화형 보고서](../outputs/reports/statistical_analysis/index.html) · [같은 결과의 Markdown](../outputs/reports/statistical_analysis/report.md).

## 구현한 것

- 일곱 통계 메뉴와 별도 가정 기반 민감도 분석 메뉴. 기존 계산 인터페이스와 정책 테스트 유지.
- 독립적인 국내 질문 5개, 시설 자료 품질 1개, 해외 질문 3개의 실제 분석.
- 질문마다 계산 코드·CSV 표·PNG/SVG·대화형 그래프·출처·기준연도·단위·한계.
- 기본 네트워크 호출 없이 한 명령으로 전체 보고서 재생성.
- 출처 원본과 정규화 자료의 SHA-256 검사, 그래프 수치와 표의 해시 보존.
- 한국·해외 지표의 정의 불일치 시 통합 비교 차단. 문헌 평균을 가상 개인 표본으로 확장하지 않음.

## 남은 자료와 한계

OECD 원문 다운로드 시도는 접근 실패였고 구조화 테이블·SDMX 식별자도 확인하지 못했다. 수집기를 성공한 것처럼 표시하지 않으며 정량 결과를 만들지 않았다. 영국 반출·재고·공정손실·출하물 품질 자료도 아직 연결하지 않았다.

국내 가구별 시간일지, 지역별 인구·가구 수, 검증 처리단가 4개, 최종 재처리수율, 개별 시설 용량이 부족하다. 시간 분포·신뢰구간·인구보정·한국과 해외 통합 순위는 미산출이다. 짧은 행정 시계열에서 정책 인과효과나 회귀 결과를 주장하지 않는다.

계약 100건 샘플은 일반 용역이며, 동일 서비스기간·지역·품목·공정의 실제 톤수와 대조한 원/t 단가는 0건이다. 구로구의 115.29억원은 공개 예산이며 총사회적 비용으로 단정하지 않는다.

영국 원본과 시설별 행은 조건부 이용허락 때문에 Git 공개 대상에서 제외했다. 소스별 이용조건과 원문 근거는 configs/external_sources.yaml 및 수집 manifest에 기록한다.

## 재현·검증

```powershell
.\.venv\Scripts\python run_statistical_analysis.py
.\.venv\Scripts\python -m streamlit run app.py
.\.venv\Scripts\python -m pytest -q
```

Streamlit 실행 테스트로 여덟 메뉴의 렌더링과 기존 민감도 영역을 확인했다. 최종 전체 회귀 테스트 **429개 통과(15.50초)**. 기존 정책 테스트도 보조 메뉴에서 실행해 비용 미입력·용량 제약·시설 대안 동작을 확인했다. 독립 분석 9개의 보고서를 최신 코드로 재생성했다. 세부 절차는 [사용법](statistical_analysis_guide.md)에 정리했다.
