# 관측값과 가정

현재 기본 모형은 2024년 구로구의 수거·선별 행정처리 흐름을 다룹니다. 전국 가정 전체나 4품목별 발생량을 추정하지 않습니다. 원표의 '발생량'을 구 전체 발생량 또는 시설 반입량이라고 단정하지 않습니다.

| 구분 | 적용 |
|---|---|
| 관측 기준선 | 보고서 수록 처리대상량·선별량·잔재량·수거운반 및 선별처리 예산 |
| 자료 기반 목표 | B는 2023년 관측 선별률을 2024년 물량에 적용하는 외생 목표 |
| 최종 재처리 수율 | 기본 85%, 민감도 70·85·95%. 해당 처리 흐름의 관측값이 아님 |
| 시간가치 | 2024 공식 최저임금 9,860원/시간을 가계 시간가치로 적용하는 가정 |
| 대안 예산 배율 | B 수거 0.95·선별 1.05배, C 각각 0.9배, D 수거 1·선별 1.1배. 정책효과 관측이 아님 |
| 추가 투자 | A/B/C는 추가 투자 가정 없음. D는 5억원을 가정 |
| 연간화 | 할인율 3%, 수명 15년은 실험 가정. 해당 시설 실측 또는 공식 권고치라고 주장하지 않음 |
| 연간 용량 | 미확인. 일일 명목용량 ×365를 임의로 사용하지 않음 |
| 가계·재처리 총비용 | 자료 부재로 결측 유지 |
| 별도 처분비 | 선별처리 예산과 중복 여부 미확인으로 별도 가산하지 않음 |

가정 적용 최종 재생원료량은 선별량 × 최종 재처리 수율입니다. 실제 선별량을 최종 재생원료량이라고 부르지 않습니다.

비교 포함비용 = 관측 수거예산 × 수거 배율 + 관측 선별예산 × 선별 배율 + 추가 신규 투자비의 연간화 금액입니다. 예산 배율은 추가 신규 투자 연간화를 포함하지 않는다고 가정합니다. 기존 설비·처분·관리비 포함 여부는 확인되지 않았습니다. 이 합계는 부분 범위의 비교 지표이며 사회적 실물비용 또는 순후생과 다릅니다.

EPR 분담금·보조금 등 이전지출과 재활용품 판매수입은 합계에 더하거나 빼지 않습니다. 생산자 설계 전환의 실물비용과 수율효과도 이번 실제 사례에서 추정하지 않습니다. 기존 D의 EPR 결합 모형 대신 설비 보강 목표를 사용합니다.

가계 시간 계산은 주당 절약 분 ×52÷60×시간가치입니다. 대상 가구 수·실측시간이 확인되지 않아 총가계비로 확장하지 않습니다. 시간가치는 조건부 정책 비용 순위에 영향을 주지 않습니다.

민감도는 일변량 실험이며 경험적 확률분포 또는 신뢰구간이 아닙니다. 수율 실험은 예상 재생원료 전환비율로 표시합니다. 재처리비 미측정으로 수율의 비용효과는 이번 합계에 포함되지 않습니다.
