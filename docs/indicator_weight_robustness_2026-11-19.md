# 가중치 허용 범위 전체에 대한 재활용 처리비율 비교

RPL 연구안 v1.1 · 확인·계산일 2026-11-19

이 문서는 [초기 지표 연구](recycling_indicator_study.md)의 구성 표준화를 확장한다. 기존 KOSIS 2024년 17개 시도·4재질 자료를 사용하여 ‘가중치 몇 가지에서 순서가 같은가?’보다 강한 질문인 **허용 집합의 모든 공통 가중치에서 비교 방향이 유지되는가?**를 검증한다. 자료는 최종 재생원료 산출량이 아닌 물질재활용 **처리량**이다. 아래 결과를 국가별 최종 H/S나 정책효과 순위로 해석하지 않는다.

## 1. 선행연구와 적용 근거

[Seth·McGillivray(2018)](https://link.springer.com/article/10.1007/s00355-018-1132-6)는 선형 종합지표의 가중치 상·하한을 명시하고 허용 집합 전체에 대해 쌍별 비교의 견고성을 평가하는 접근을 제시한다. 이 방법론은 본 분석의 근거가 되지만, 허용 상·하한이 객관적으로 결정됐다거나 재활용 지표의 경험적 타당성이 검증됐다는 뜻은 아니다. 연구 목적과 합의에 따라 가중치 집합을 정하는 판단은 여전히 남는다.

전국 발생비중을 기준으로 한 단일 S를 본값으로 유지하면서 세 가지 점차 넓어지는 집합을 선언한다. 해당 지역을 제외한 전국 비중은 지역마다 기준이 달라지므로 공통 가중치 집합을 정의하는 세 벡터에는 넣지 않는다.

## 2. 세 집합의 정의와 포함 관계

전국 발생비중, 17개 시도의 재질 구성비 단순평균, 4재질 균등 가중치를 각각 `v₁,v₂,v₃`라 한다. 가중치 값과 구체적 상·하한은 출력 표 `weight_reference_vertices.csv`, `weight_domain_bounds.csv`에 보존한다.

```text
W_hull = { α₁v₁ + α₂v₂ + α₃v₃ : α_k ≥ 0, Σα_k = 1 }
l_m = min_k v_km,  u_m = max_k v_km
W_box = { w : l_m ≤ w_m ≤ u_m, Σw_m = 1 }
W_all = { w : w_m ≥ 0, Σw_m = 1 }
W_hull ⊆ W_box ⊆ W_all
```

세 벡터의 볼록혼합은 각 좌표가 그 벡터들의 최소·최대 안에 있고 합이 1이므로 첫 포함 관계가 성립한다. 각 좌표가 비음수이므로 두 번째도 성립한다. 좌표별 상·하한만 적용한 W_box는 세 벡터의 혼합으로 표현되지 않는 조합을 포함할 수 있다. 따라서 세 대안 또는 그 모든 혼합에서 결론이 같다는 사실만으로 W_box 전체의 결론을 보장하지 않는다.

W_all은 0과 한 재질에 전부 배정하는 극단을 허용하는 닫힌 단체다. 이는 보수적인 스트레스 검토이며 실제 기본 가중치로 제안하는 값은 아니다. 엄격히 양수인 가중치 집합의 경계까지 포함하면 극값을 달성하는 증인 벡터를 제시하기 쉽고 극단에서도 유지되는 비교를 보장할 수 있다. 경계에서 동점이 가능한 약한 우위는 엄격한 우위와 구분한다.

## 3. 같은 공통 가중치를 사용하는 쌍별 검증

지역 A,B의 재질별 관측 처리비율을 `p_Am,p_Bm`라 하면,

```text
d_AB(w) = S_A(w) − S_B(w) = 100Σ_m w_m(p_Am − p_Bm)
d⁻ = min_(w∈W) d_AB(w),  d⁺ = max_(w∈W) d_AB(w)
```

`d⁻>0`이면 A가 모든 허용 가중치에서 높고, `d⁺<0`이면 B가 높다. 양·음수가 모두 가능하면 허용 가중치에 따라 우열이 뒤집힌다. 0을 포함하지만 한 방향으로만 차이가 나는 경우는 동점 가능성을 포함하는 약한 비교로 분류한다. 수치 허용오차는 계산상의 작은 오차를 다루는 값이며 통계적 유의성 기준이 아니다.

여기서는 두 지역에 **동일한 w**를 적용한다. 지역 A의 점수 하한과 B의 점수 상한을 각각 다른 가중치로 계산하면 실제 공통 기준에서 불가능한 조합이 생길 수 있다. 따라서 두 별도 구간의 겹침만으로 비교 불가능을 판정하지 않고 공통 w에서 차이를 직접 최적화한다.

### 선형 극값의 계산과 증명

W_hull에서 `d(Σα_kv_k)=Σα_kd(v_k)`이므로 점수 차이는 세 기준 벡터의 점수 차이들의 가중평균이다. 최솟값·최댓값은 기준 벡터 중 하나에서 달성된다. 이것은 혼합 공간 전체의 증명이며 무작위 표본 가중치 시뮬레이션이 아니다.

W_box에서 선형 목적의 계수를 `c_m`라 하자. 먼저 모든 재질에 하한 l을 배정하고, 남은 `1−Σl`을 c가 작은 재질부터 상한까지 배정하면 최솟값을 얻는다. 최적이라고 가정한 해에서 계수가 작은 재질 i에 추가 배정 여지가 있고 더 큰 계수 j가 하한을 초과한다면, j의 일부 가중치를 i로 옮길 때 목적값은 증가하지 않는다. 이 교환을 반복하면 위 순서 배분 해가 된다. 최댓값은 −c를 최소화해 얻는다. 구현은 별도의 선형계획 최적화 결과와 비교하는 테스트로 확인한다.

W_all에서는 `min_m c_m`와 `max_m c_m`가 극값이다. 한 재질에 가중치를 전부 주는 벡터가 이를 달성한다. 모든 재질에서 A가 B 이상인 비교는 이 집합에서도 방향이 뒤집히지 않는 파레토 비교다.

## 4. 실자료 결과

2024년 17개 시도의 서로 다른 지역쌍은 `17×16/2=136`쌍이다.

| 허용 집합 | 비교 방향 유지 | 방향 역전 가능 |
|---|---:|---:|
| 세 기준 가중치의 모든 혼합 W_hull | 123쌍 | 13쌍 |
| 재질별 최소·최대와 합계 1의 전체 W_box | 118쌍 | 18쌍 |
| 모든 비음수 공통 가중치 W_all | 83쌍 | 53쌍 |

현재 실자료에서는 방향 유지 쌍의 모든 구간이 0에서 엄격히 떨어져 있고 동점·약한 우위 쌍은 없다. 더 넓은 집합의 보장 비교는 더 좁은 집합의 보장 비교에 포함된다. 특히 세 대안 혼합에서 유지되는 123쌍 중 5쌍은 좌표 경계 전체로 범위를 넓히면 뒤집힐 수 있다. 따라서 ‘3개 대안에서 순서가 같음’과 ‘각 재질의 최소·최대 전체에서 순서가 같음’을 구별할 실증적 이유가 있다.

이 수는 가중치에 확률을 부여해 얻은 승률이나 신뢰수준이 아니다. 136개 비교를 독립 표본으로 보지도 않는다. 같은 지역·자료가 여러 쌍에 반복 등장한다. 가중치 집합을 넓히는 것은 추가 자료 확보가 아니라 더 강한 조건에서 결론을 보장할 수 있는지 확인하는 분석이다.

## 5. 불확실한 재질률과 순위 외곽 범위

재질별 비율을 관측 구간 `[L_im,U_im]`으로만 알 때는 비음수 w에서

```text
d⁻ = 100 min_(w∈W) Σw_m(L_Am − U_Bm)
d⁺ = 100 max_(w∈W) Σw_m(U_Am − L_Bm)
```

를 사용한다. 이는 재질·지역별 불확실성이 각각의 구간 안에서 독립적으로 변할 수 있다는 직사각형 가능집합에 근거한다. 공통 수율이나 물질수지 등 추가 종속 제약이 있으면 이 구간은 보수적일 수 있다. 경계를 모르는 자료를 자동으로 조화하거나 미확인 값을 중간값으로 대입하지 않는다. 위 실증 표는 관측 처리비율이므로 측정 구간을 추가로 추정하지 않았다.

순위는 자신보다 엄격히 높은 지역 수에 1을 더한 방식으로 정의한다. 항상 자신보다 높은 지역 수는 가능한 최고 순위의 하한을 주고, 높아질 가능성이 있는 지역 수는 가능한 최저 순위의 상한을 준다. 쌍별 가능성을 합친 결과라 여러 지역을 동시에 비교하는 하나의 w에서 양 끝 순위가 실현된다는 보장은 없다. 출력의 `rank_lower_outer`, `rank_upper_outer`는 **보수적 외곽 범위**이며 날카로운 순위 식별구간이나 신뢰구간이 아니다.

## 6. 과학적 해석의 경계와 추가 근거

가중치에 견디는 비교도 KOSIS의 처리량·발생량 정의를 전제로 한다. 실제 최종 산출, 수출입 귀속, 무수 물질 환산, 발생 코호트가 확보되지 않아 최종 H/S 국가 순위는 여전히 미식별이다. 시설·소득·제품 설계·정책 채택의 교란을 제거한 인과효과도 아니다.

[JRC 2025 보고서](https://publications.jrc.ec.europa.eu/repository/handle/JRC142860)는 EU-27 플라스틱 2022년 모형에서 적정 수거 86%와 EOL 재활용률 19.6%를 별도로 발표한다. 수거 전체에는 처분 경로도 있으므로 이 두 값을 감산하거나 나누어 재생 공정손실·수율을 만들지 않는다. [Eurostat의 2026-10-29 발표](https://ec.europa.eu/eurostat/en/web/products-eurostat-news/w/ddn-20261029-2)의 재활용 42.0%도 전체 처리량을 분모로 하며 수입 포함·수출 제외 경계를 갖는다. 이런 수치를 발생국 기준 municipal 최종 회수율과 곧바로 비교하지 않는다. 확인 범위는 [추가 근거 노트](indicator_followup_evidence_2026-11-19.md)와 [출처 원장](../data/indicator_followup_sources.json)에 적었다.

## 7. 재현과 결과 파일

```powershell
.\.venv\Scripts\python scripts/run_recycling_indicator.py
.\.venv\Scripts\python -m pytest tests/test_weight_robustness.py tests/test_recycling_indicator_report.py -q
```

`outputs/tables/recycling_indicator/`의 `weight_comparisons.csv`는 3개 집합의 모든 쌍을, `weight_witnesses.csv`는 각 극값을 만드는 가중치와 재질별 기여도를 담는다. 기여도 합은 해당 쌍의 극값과 같고 가중치 합은 1이다. `weight_reference_vertices.csv`와 `weight_domain_bounds.csv`에서 허용 집합을 재구성할 수 있다. `weight_rank_outer.csv`는 위 보수적 순위 외곽 범위다. 그림과 원본 수치를 함께 보존하고 입력·분석 코드 SHA-256을 manifest에 남긴다.
