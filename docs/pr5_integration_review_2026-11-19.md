# PR #5 통합 및 후속 지표 연구

확인일: 2026-11-19 (Asia/Seoul)

## 통합 대상

PR의 `codex/regional-recycling-2024`와 `main`의 재활용 지표 연구를 통합했다. Streamlit 전체 파일이 줄바꿈 차이까지 포함해 충돌했으므로 한쪽 파일을 통째로 선택하지 않고 기능 단위로 결합했다.

- PR의 월별 행정코드·명칭 감사 상태, 조례 연혁 후보와 행정코드 교차표, 관련 다운로드를 보존한다.
- main의 재활용 지표 연구 메뉴, H/S 산식·결측 처리, 출처·보고서 다운로드를 보존한다.
- 조례 후보를 실제 운영정책으로 승격하지 않는다. 코드·명칭 대조는 GIS 경계와 정책 적용권역의 검증을 대신하지 않는다.
- 최종 재생원료 산출률과 정책 인과효과는 여전히 미식별이며, 관측 처리량을 최종 산출로 대체하지 않는다.

## 확인한 회귀 문제와 보완

1. 조례 응답의 포함 텍스트에서 `OC=` 이후를 정제하는 정규식의 공백 표현을 수정했다. URL 쿼리와 중첩 응답에 포함된 인증값을 모의 응답으로 검사한다.
2. 완료된 월별 감사 재실행에서 코드·명칭 불일치가 나타나면 과거 성공 상태를 철회한다. 준비 manifest와 행별 호환성 표시에 재검토 상태를 전달한다.
3. 자치법규 본문은 문서 식별자·본문 형태를 확인한 뒤 수집 건수로 센다. HTTP 200이라는 사실만으로 인증·서비스 오류 JSON을 본문으로 인정하지 않는다.
4. 후보 목록이 0건인 경우도 헤더를 가진 빈 교차표와 0건 집계를 반환한다. 미매칭·모호한 기관명·시도 단위 후보를 시군구 전체 정책 노출로 자동 환산하지 않는다.
5. 목록 조회 후 본문 예산이나 검색 범위를 바꿔 실행하면 과거의 목록 전용 캐시를 그대로 반환하지 않는다. 요청조건·완료 상태·후보 CSV 해시가 맞는 캐시만 재사용한다. 빈 감사 이슈표에도 헤더를 남긴다.

동일한 KOSIS 2024년 17개 시도·4재질 처리자료에 공통 가중치 집합을 적용했다. 지역쌍은 136개다.

| 허용 가중치 집합 | 방향이 유지되는 쌍 | 우열이 바뀔 수 있는 쌍 |
|---|---:|---:|
| 전국 비중·시도 비중 평균·균등의 모든 볼록혼합 | 123 | 13 |

가중치 집합을 넓히면 보장되는 비교가 줄 수 있다는 결과다. 특정 가중치가 객관적으로 옳다거나 특정 지역 정책의 인과효과가 크다는 뜻은 아니다. 최적화는 지역마다 따로 유리한 가중치를 주지 않고 각 지역쌍에 하나의 공통 가중치를 적용한다. 극값을 만드는 재질별 가중치와 기여도를 CSV로 보존한다.

[가중치 연구 방법과 증명](indicator_weight_robustness_2026-11-19.md), [추가 공식·학술 근거](indicator_followup_evidence_2026-11-19.md)를 함께 확인할 수 있다. 기관 모형과 최신 공식 발표는 기존 실측치에 합산하지 않는다.

통합본 검증 결과는 전체 테스트 **515개 통과, 시군구 비배포 자료 의존 검증 1개 건너뜀**이다. 종합 분석과 지표 연구 보고서 생성, Python 컴파일, 충돌 표식·공백 검사도 통과했다.

2026-11-20 후속 변경에서 현재 입력 로스터·12월 코드·월별 원문 증빙과 감사 지문을 대조하도록 보완했다. 기존 지문 없는 감사와 입력 변경은 검증 상태를 유지하지 못하며, 현재 결합에는 별도 재생성 표지가 필요하다. [증빙 계약과 재현 순서](boundary_evidence_contract_2026-11-20.md)를 따른다. 이 확인은 GIS 도형·실제 정책 노출 검증을 대신하지 않는다.

후속 최종 검증은 **587개 통과, 건너뜀 0개**다. 공식 원표의 229개 시군구·4재질 916행과 12개월 MOIS 자료를 확보해 실자료 검증 및 보고서 재생성을 수행했다. 월별 원문 72개를 사용한 감사 재실행은 네트워크 요청 없이 완료됐으며 현재 입력 연결도 검증했다. 실제 정책·성과 결합은 0행으로 유지한다.

같은 날 법령정보 연결을 확장했다. 법제처 연혁 후보 659버전 중 523버전을 2024 통계지역 코드에 연결하고 본문 60건에서 조문·부칙 등 텍스트 1,031항목을 추출했다. 버전 식별자·조문 위치·원문 해시·인증값 없는 공개 열람 링크를 앱 검색과 보고서 CSV에 제공한다. 원문·후보·지역 입력·산출물 변경 시 현재 수치를 보류하고, 법령 버전 확인을 실제 시행·정책 효과로 승격하지 않는다. 최신 전체 검증은 **683개 통과, 건너뜀 0개**이며 보고서 재생성도 완료했다.
