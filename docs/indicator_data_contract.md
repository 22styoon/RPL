# 최종 물질회수 지표의 입력 계약

범위 v1: 공통 municipal 건식 재질 바스켓. 연구 설명은 [연구 보고서](recycling_indicator_study.md)를 따른다. 실제 KOSIS·NEA 처리자료는 이 계약을 충족한 최종 산출 자료가 아니므로 자동 주입하지 않는다.

2024년 공단 판매표, 사업체 생산 공시, 생산량 원장 서식 등 9개 후보의 충족 여부를 대조했다. 발생 코호트와 무수 대상질량이 연결되는 실측행은 아직 없다. [공식 자료 후보와 원장 확보 경로](f_output_and_collection_evidence_2026-11-22.md)

| 필드 | 뜻 / 검증 |
|---|---|
| entity, year, material | 국가/지역·발생 코호트 역년·공통 재질. 키 중복 불가 |
| generated_t | 무수 대상물질 환산 발생량. 유한한 양수, metric tonne |
| secondary_output_t | 같은 발생 코호트·원산지의 이용가능 최종 재생물질량. 미확인은 빈 값 |
| recycling_input_t | 선택. 위와 동일한 경계의 공정 투입 대상물질량 |
| output_lower_t, output_upper_t | 선택. F 미확인 시 증빙 가능한 구간. 둘 다 필요. 점 관측과 동시 제공 불가 |
| scope_id | `municipal_dry_materials_v1` — 감사된 공통 건식 재질 바스켓 프로파일. 구체적인 재질 목록은 고정 가중치 키로 명시. 실제 시범은 4재질이며 원리를 설명하는 가상 사례는 2재질 |
| denominator_id | `domestic_generated_material` |
| measurement_point | `secondary_material_output` |
| mass_basis | `dry_material_equivalent` |
| trade_basis | `domestic_origin_traced` |
| period_basis | `generation_cohort` |
| source_id, source_locator | 출처 ID와 원표 절·셀·계근/감사 증빙 위치. 빈 값 불가 |

가중치는 미리 고정한 재질 이름의 사전이다. 모든 entity/year에 각 재질의 행이 하나씩 필요하며 합은 1이어야 한다. 자료 없는 재질도 G가 확인되면 F를 빈 값으로 남긴 행을 포함한다. G가 없거나 0이면 자동 표준화하지 않는다. 무수 환산이 불가능한 습윤 통계를 같은 프로파일로 표시하면 안 된다.

프로그램은 코드의 경계명·질량 제약을 확인한다. 실제로 원산지가 추적됐는지, 제품 규격을 충족했는지, 복합품의 재질 중복을 제거했는지는 원문과 감사 증빙으로 사람이 확인해야 한다. 범위명만 맞게 입력한 수치를 검증된 사실로 자동 승격하지 않는다.

실제 최종 F를 확보하기 위해 추가할 원장에는 다음 열이 필요하다. 국가×재질 지표표를 만들기 전에 경로·시설·코호트 원장을 감사한다.

| 원장 항목 | 필요한 이유 |
|---|---|
| 국내 발생분의 국내 처리 최종 산출, 국외 처리 최종 산출 | 발생국 기준 귀속, 수출 신고량과 최종 회수량 구분 |
| 원산지·발생 코호트, 도착 시설, 처리일, 최종 제품 거래·규격 | 수입분 제외와 미처리 수출·중간 선별품 구별 |
| 유입·산출 수분, 오염물·첨가물, 대상 물질 함량 | 동일 질량 기준과 F≤G의 물리적 정합성 |
| 기초/기말 재고, 반려·잔재·연료·처분량, 시설간 이동 ID | 재고 시차·중복·연료화·누락 확인 |
| 재질 분류 대응표와 표본 오차·미보고 범위 | 공통 바스켓 대응과 측정 불확실성 |
| 분류·수분 환산·재고 귀속 규칙의 버전과 감사자 | 국가·시점 간 규칙 일관성과 재현성 |

국내 최종 산출량이 없을 때 기존 `material_recycling_t`를 `secondary_output_t`로 이름만 바꾸지 않는다. 해외로 보낸 플라스틱 100t 중 최종 펠릿이 60t으로 확인됐으면 원산지 발생국에는 60t을 한 번만 귀속한다. 이 수치는 규칙을 설명하는 예시이며 실제 수출 관측이 아니다.
