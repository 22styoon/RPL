# 실제 자료 조사 기록

확인일: 2026-11-15. 현재 모형은 전국 합성 예제에서 실제 지역 사례로 기본 입력을 변경했습니다.

## 국가통계포털을 주자료로 사용

KOSIS의 [생활폐기물 통계표](https://kosis.kr/statHtml/statHtml.do?orgId=106&tblId=DT_106N_29_2020005&conn_path=I2)를 확인했습니다. 공식 공개 지표의 시계열 응답을 직접 수집해 전국 추세에 반영했습니다. 인증 OpenAPI로 2024년 상세 자료와 분류 메타데이터를 실제 수집하고, 전국·17시도 합계와 단위를 검증했습니다. 이 통계를 구로구 시설 수율과 혼합하지 않습니다.

## 채택한 근거

[구로구의회 연구보고서](https://www.guroc.go.kr/kr/bbs/download.do?bbs_id=memnotice&uid=10C5C2B6918247C7947B3A54914B8714)의 표5·6(인쇄57~58쪽)을 수동 전사했습니다. 원자료는 구로구청 자료라고 명시되어 있습니다. 예산 단위 천원을 원으로 정규화합니다. A 계산이 관측 선별량과 두 예산 합계를 재현하는지 테스트합니다.

[구로구 공식 시설 안내](https://www.guro.go.kr/www/contents.do?key=2672)는 혼합 배출 재활용품을 수선별·자동선별한다고 설명합니다. 따라서 이번 기준선은 완전 품목별 분리배출의 실적이 아닙니다. A/B/C/D 명칭은 현행 및 효율·비용 변화 실험으로 바꿨습니다.

[최저임금위원회](https://www.minimumwage.go.kr/minWage/policy/decisionMain.do)의 2024년 시간급을 가구당 시간 절약 계산의 기준으로 사용합니다. 실제 기회비용 추정치라고 주장하지 않습니다.

[전국 e-나라지표 원표](https://www.index.go.kr/unity/potal/eNara/sub/showStblGams3.do?freq=Y&idx_cd=1477&period=N&stts_cd=147701)는 별도 추세 확인에만 사용합니다.

## 채택하지 않은 결합

전국 가구 수를 구로 공공처리량에 곱하지 않았습니다. 공동주택 민간 수거 등을 포함한 대상 가구 범위를 맞출 수 없기 때문입니다. 품목별 비중도 확인되지 않아 4품목으로 임의 분해하지 않았습니다.

다른 도시 선별률·운영지원금은 품목 구성, 처리 단계, 재정 범위가 달라 구로의 실제 정책효과나 원가로 이식하지 않았습니다. 미확인 '86.1% 대 21%' 주장도 사용하지 않습니다.

## 남은 데이터

같은 처리 흐름의 최종 재생원료 생산량, 재처리 원가, 잔재처리 비용 범위, 수거대상 가구와 실제 분리배출 시간, 연간 실가동 용량이 필요합니다. 이 자료가 확보되기 전에는 총사회적 비용 최소화 또는 전국 적용 정책 권고로 해석할 수 없습니다.

## 수율 문헌 검토

[김건국 외(2013)의 폐합성수지 시설 물질흐름 연구](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001757031)는 시설별 평균 수율을 제시하지만, 오래된 플라스틱 시설 조사입니다. 종이·금속·유리를 포함한 구로 혼합 전체 품목의 수율로 외삽할 근거가 되지 않습니다. 따라서 85%는 D가정으로 유지하고 문헌은 참고 목록에만 기록합니다.

## 인증 조회 검증

전국 대비 17개 시도 합계를 경로·처리항목별 294개 경우에서 검산해 일치를 확인했습니다. 처리량의 재활용 소계는 에너지회수를 포함하므로 물질재활용을 따로 집계합니다. 전국 4품목 결과와 중복 방지 규칙은 data_dictionary.md에 기록했습니다. 기존 시설 사례의 최종 수율 가정을 이 처리량으로 대체하지 않습니다.
