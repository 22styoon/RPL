상태: 실제 자료 수집·집계, 지역별 정책 모형, 구로구 시설 실험, 화면·내보내기 통합 완료. 전체 회귀 검증 109개 통과.

## 1. 문제와 개발 목표

이 프로젝트는 분리배출 및 처리 개선 대안이 재생원료 확보와 비용에 어떤 차이를 만드는지 검토하는 실험 도구다. 목표는 관측 현황에 정책 효과·수율·비용 가정을 명시적으로 적용하고, 목표 재생원료율과 예산·용량 제약 아래 비교 가능한 대안을 찾는 것이다.

현재 확보한 KOSIS 자료는 발생·처리 현황을 제공하지만, 최종 재생원료 수율과 정책 효과, 지역별 비용을 제공하지 않는다. 따라서 지금의 산출물은 **주어진 가정과 유한한 대안 안에서의 조건부 비교**다. 실제 전국 비용 최적정책을 확정한 단계가 아니다.

전국·시도 현황 모형과 구로구 시설 모형은 관측 범위가 다르므로 분리한다. 구로구의 수거·선별 예산을 전국·시도 발생량에 비례해 자동 외삽하지 않는다.

## 2. 실제 확보한 자료와 집계 범위

KOSIS 통계표 `DT_106N_29_2020005`의 2024년 인증 OpenAPI 응답을 실제 수집했다. 이번 보고서 작성 시 저장 파일의 행 수와 집계 키를 다시 확인했다.

| 항목 | 확인 결과 |
|---|---|
| 상세 관측 셀 | 5,292행 |
| 분류·항목 메타데이터 | 946개 |
| 지역 | 전국과 17개 시도, 총 18지역 |
| 지역별 관측분류·처리항목 | 42분류 × 7처리항목 |
| 대응 4품목 | 폐지류·폐합성수지류·폐금속류·폐유리류 |
| 지역·배출방식·품목 집계 | 18지역 × 2배출방식 × 4품목 = 144행 |
| 배출방식 합산 집계 | 18지역 × 4품목 = 72행 |
| 72행의 지역·품목·연도 키 중복 | 0건 |

분류 코드의 부모 계층을 복원해 혼합배출과 재활용 가능자원 분리배출에서 대응 품목을 묶었다. 관측된 상위 품목이 있으면 하위 품목을 다시 더하지 않으며, 전국과 17개 시도를 함께 합산하지 않는다. 필요한 관측이 결측이면 합계도 결측을 유지한다. 원표 코드를 결과 행에 보존해 집계 근거를 추적할 수 있다.

4품목은 원표에 대응하는 파생그룹이다. 영농폐비닐과 전자제품·가구 등 복합제품의 재질을 포함한 전국 모든 재질의 총량을 뜻하지 않는다. 처리경로 합계에는 원표 반올림에 따른 최대 약 0.4t/년 차이가 있어 이를 곧바로 물질수지 오류로 판정하지 않는다.

전국·17시도 합계를 경로·처리항목별 294개 경우에서 검산한 결과도 기존 자료 문서에 기록되어 있다. 2020~2024년 공개 전국 추세는 별도 수집 경로이며, 상세 인증 자료와 구분한다.

관련 자료는 [수집 설정과 결과](kosis_setup.md), [데이터 사전](data_dictionary.md), [조사 근거](research.md)에 정리되어 있다.

## 3. 관측값·가정·미확인의 구분

| 구분 | 현재 사용 내용 | 해석 |
|---|---|---|
| 관측 자료 | KOSIS 지역·품목별 발생량, 물질재활용 처리량, 에너지회수, 소각·매립 등 | 공식 처리 현황 |
| 관측 자료 | 구로구 2024년 처리대상량 13,195t, 선별량 7,733t, 선별 잔재 5,462t, 수거·선별 예산 | 구로구 수거·선별 행정처리 흐름 |
| 외생 가정 | 품목별 최종 재처리 수율, 정책별 처리비율 변화·수율 변화·도입비중 | 관측 정책효과가 아닌 실험 입력 |
| 외생 가정 | 비용단가, 추가 투자, 할인율·수명, 가계 시간가치·시간 변화 | 입력 근거를 따로 확인해야 하는 경제 가정 |
| 미확인 | 실제 최종 재생원료 생산량, 지역별 일치 범위의 비용, 시설별 가동 가능 용량, 법규·허가조건 충족 | 확정 결론을 제한하는 자료 공백 |

KOSIS의 **물질재활용 처리량은 최종 재생원료 생산량과 다르다**. 원표의 재활용 소계에는 물질재활용과 에너지회수가 함께 들어 있으므로, 에너지회수를 최종 재생원료에 포함하지 않는다. 최종 재생원료량은 물질재활용 처리량에 가정 수율을 곱해 계산한다.

처리비율을 관측 수거율·선별률로 임의 분해하지 않는다. 발생량에서 물질재활용 처리량을 뺀 양 전체도 선별 잔재나 최종처분량으로 부르지 않는다. 그 안에는 기존 에너지회수·소각·매립·기타 경로가 포함된다.

KOSIS 자료에는 이 모형에 필요한 지역별 비용이 없다. 구로구 예산은 지역별 단가를 대신할 근거가 아니며, 전국 정책의 비용으로 자동 전환하지 않는다. 미입력 비용은 0원으로 처리하지 않는다.

자료 흐름은 저장된 KOSIS 응답·메타데이터 → 지역·4품목 집계 → 관측 기준선 → 가정을 적용한 대안 → 제약 판정·비용 비교 → 한글 표·그래프·다운로드 순서다. 수집 자료와 정책효과 가정은 결과와 내보내기에서도 구분한다.

### 구로구 시설 확장 API

- `copy_with_alternatives(config, alternatives=None)`: 원본을 보존하며 완전한 시나리오 사전을 추가한다.
- `evaluate_facility(config, scenario, processing_yield=None)`: 대안별 수율을 적용해 결과 사전과 흐름표를 반환한다.
- `compare_facilities(config, target=None, annual_budget_cap=None, alternatives=None, alternative_processing_yield=None, require_known_capacity=False)`: 조건부 비교표를 반환한다.
- `minimum_cost_curve(config, targets, ...)`: 여러 목표에서 주어진 대안 중 최소 비교비용을 반환한다.

대안별 수율은 평가 직전 설정을 깊은 복사한 뒤 기존 평가식에 전달한다. 대안 수율 실험이 기준선 A의 자체 수율과 재생원료율 하한을 낮추지 않도록 고정했다. 용량은 각 시나리오의 `capacity_t`에 t/년으로 입력한다.

용량이 `None`인 대안은 미확인이다. 기본 모드에서는 조건부 후보로 남지만 검증 완료로 표시하지 않는다. `require_known_capacity=True`이면 미확인 후보도 제외한다. 알려진 용량을 충족해도 전체 검증 상태인 `fully_verified`는 거짓이다. 비교비용은 알려진 수거·선별 예산과 추가 투자 연금액이며 총사회적비용이 아니다.

| API | 계약 |

## 5. 지역별 조건부 정책 실험 설계

선택한 한 지역의 동일 연도 4품목 발생량을 고정 분모로 사용한다. 품목별 관측 물질재활용 처리비율에 정책 처리비율 변화폭을 적용하고, 처리량에 가정 최종수율을 곱한다.

- `treatment_change_pp`: 원래 물질재활용 처리비율에 더하는 절대 퍼센트포인트 변화다. 50%에 +5pp를 적용하면 55%다.
- `yield_change_pp`: 품목별 기준 최종수율에 더하는 절대 퍼센트포인트 변화다.
- `baseline_yields`: 품목별 기준 최종수율이며 기본 0.85는 관측값이 아닌 D등급 가정이다.
- 비율은 0~1 범위를 벗어나면 제한하고 그 적용 사실을 표시한다.
- A는 해당 실행의 고정 기준선이다. 대안 효과·도입비중을 바꾸는 동안 A의 수율과 하한을 함께 낮추지 않는다.
- `scan_adoption`에서는 B/C/D의 25%·50%·75%·100% 도입비중을 검토한다. 효과·추가 투자·용량·생산자 추가원가를 선형 보간하는 방식도 외생 가정이다.

도입비중을 연속적으로 최적화하거나 전국 시설 배치를 직접 최적화하는 모형은 아니다. 결과는 설정한 정책·도입비중의 유한 조합 중 비교 가능한 대안을 가리킨다.

### 비용과 가계 범위

경제 비교에 필요한 기본 단가 네 개는 다음과 같다. 단위는 원/t이며 초기값은 모두 미입력이다.

| 설정 항목 | 의미 |
|---|---|
| `collection_per_t` | 수거 대상 물량당 수거 비용 가정 |
| `material_processing_per_t` | 물질재활용 처리량당 비용 가정 |
| `other_treatment_per_t` | 물질재활용 외 처리량당 비용 가정 |
| `processing_residue_per_t` | 가정 수율 적용 후 처리 손실량당 비용 가정 |

네 단가가 모두 입력되기 전에는 `comparison_cost`를 결측으로 두고 비용 순위를 대기한다. 알려진 부분합은 별도 정보로만 표시한다. 사용자가 0원을 명시적으로 입력한 경우와 미입력을 구분한다. 단가와 추가 투자·생산자 원가 등은 가정 비용이며, 비용 포함범위를 함께 표시한다.

가계 시간비용 포함 여부는 `include_household`로 선택한다. 포함할 경우 해당 지역·폐기물 범위에 맞는 가구 수와 기준 분/주 등 필요한 입력을 요구한다. 공식 최저임금을 시간가치로 사용하는 것도 적용 가정이며, 지역 발생량에 전국 가구 수를 임의 결합하지 않는다.

### 목표·예산·용량과 불확실성

재생원료율 하한은 동일 실행의 A 재생원료율과 사용자 목표 중 더 높은 값이다. `annual_public_budget`는 가계·생산자 비용을 제외한 가정 공공지출에만 적용한다. `material_capacity_t`는 4품목의 물질재활용 처리량 합계에 적용한다. 서로 다른 비용·처리 단계를 섞어 제약을 판정하지 않는다.

미확인 용량과 법규·허가조건은 충족으로 간주하지 않는다. 최저비용 후보가 있어도 법적·시설적 실행 가능성과 총사회적 경제성이 확정됐다고 표시하지 않는다.

목표곡선은 유한 대안의 단계형 최소비용곡선으로 만들고, 충족 대안이 없는 목표는 결측으로 남겨 선을 연결하지 않는다. 민감도에서는 품목별 수율·정책효과·비용 가정 변화에 따른 비교 결과를 다시 계산한다.

실행 ZIP에는 결과뿐 아니라 지역·연도·분모·비용 포함범위·미관측 항목·제약 상태·현재 입력값·출처를 포함하는 재현 계약을 둔다. CSV는 한글 BOM 인코딩을 사용한다. 화면에서 바꾼 값을 기록해야 동일한 조건의 결과를 재현할 수 있으며, 결과 CSV를 직접 수정하는 것은 모형 설정 변경이 아니다.

로컬 인증정보와 개인정보는 보고서나 실행 결과에 넣지 않는다. 이번 보고서 작성 과정에서도 로컬 인증키 파일을 열거나 키를 기록하지 않았다.

## 8. 해석 한계

현재 분석으로 확인할 수 있는 것은 관측 현황과 입력 가정이 주어졌을 때 대안의 상대적 물량·비용·제약 상태가 어떻게 달라지는지다. 실제 정책의 인과효과, 품질 기준을 만족하는 최종 재생원료 생산량, 모든 지역의 실제 비용 최적정책을 확인한 것은 아니다.

주요 제약은 지역별 비용 미관측, 최종수율·정책효과 가정, 단일 연도의 현황, 고정 발생량, 대응 4품목의 제한된 범위, 선형 도입 가정, 시설별 공간·가동·계약 제약 미반영이다. 수입·수출 및 지역 간 처리 이동, 시장가격·품질 변화, 중복 포함 가능 비용도 추가 검토가 필요하다. 법규·허가와 용량 검증이 완료되지 않았으므로 결과를 즉시 시행 가능한 정책으로 해석하면 안 된다.

## 9. 남은 우선 과제와 추가 자료 요청

1. **회귀 검증 유지**: 기본 비용 미입력 시 순위 대기, 비용범위 선택, 고정 기준선, 목표·예산·용량, 목표곡선의 결측·단조성, 민감도, ZIP 실행값 일치를 109개 통합 검증으로 확인했다. 실제 자료나 효과 모형 변경 시 같은 검증을 유지한다.
2. **비용 근거 확보**: 선택 지역·2024년·대응 폐기물 범위가 맞는 수거·물질재활용·기타 처리·처리 잔재 비용을 원/t로 제공받는다. 계약 총액과 대상 처리량, 포함 운송·처분 단계, 세금·보조금·이전지출, 기존 예산과의 중복 여부를 함께 요청한다. 지자체 결산·위탁계약·시설 운영자료 등 출처와 가격연도가 필요하다.
3. **최종수율과 정책효과 보정**: 품목별 시설 투입량·최종 적격 재생원료량·오염도·품질 기준과 측정기간을 요청한다. 정책 전후 또는 비교군의 처리비율 변화 자료를 확보해 처리효과와 최종수율을 구분한다. 관측이 없는 품목을 다른 재질의 시설 수율로 자동 대체하지 않는다.
4. **시설·투자·법규 제약 확보**: 시설별 적용 단계, 명목·실가동 용량, 연간 가동일, 기존 계약 물량, 추가 투자 견적·시점·수명·유지비를 요청한다. 적용 법령·조례·허가조건은 조문과 기준일을 받아 별도로 검토한다.
5. **가계·생산자 범위 확정**: 해당 수거체계에 실제 포함되는 가구 수, 분리배출 시간 조사, 정책 도입 시 시간 변화, 생산자 추가원가의 산정 근거를 요청한다. 지역 전체 가구 수와 공공처리 물량의 범위를 먼저 맞춘다.
6. **설명과 재현성 점검**: 관측 처리량과 가정 최종량, 물질재활용과 에너지회수, 공공지출과 선택한 비교비용을 화면·CSV·ZIP에서 일관되게 구분한다. README·방법론·정책 실험 사용법은 통합 동작에 맞춰 갱신했으며, 이후 모형 변경 시 함께 관리한다.

다음 검토의 판단 기준은 “추천 대안이 나오는가”만이 아니다. 어떤 자료와 가정이 추천을 만들었는지, 비용·용량이 미확인일 때 결론을 유보하는지, 동일 입력으로 결과를 재현할 수 있는지를 함께 확인해야 한다.

## 10. 기본 실행 결과와 재현 명령

기본 지역은 전국, 품목별 최종수율은 모두 85% 가정이다. 대응 4품목 발생량은 7,269,015.7톤/년, 관측 물질재활용 처리량은 3,129,884.1톤/년이다. 이를 적용한 A의 예상 최종 재생원료량은 2,660,401.485톤/년, 가정 전환비율은 약 36.60%다. 이 분모는 생활폐기물 전체가 아니라 대응 4품목이다.

기본 B는 약 38.23%, C는 약 34.05%, D는 약 42.68%로 계산되지만 모두 입력한 정책 효과·수율 가정의 결과다. C는 A 유지 조건에 미달한다. 단가가 미입력이므로 기본 실행에서 최소비용 정책은 선정하지 않는다.

```powershell
.\.venv\Scripts\python run_policy.py
.\.venv\Scripts\python run_policy.py --region 서울 --target 0.40 --scan-adoption
.\.venv\Scripts\python -m pytest -q -p no:cacheprovider
```

명령행과 화면은 같은 입력 설정·제약·목표 경계점으로 결과를 생성한다. 실험 ZIP과 outputs/policy_runs/latest/의 결과·입력 JSON을 함께 보존하면 실행 조건을 검토할 수 있다. 적용 비중은 관측한 전환 가구 비율이 아니라 처리비율·수율 효과 변수의 강도이며, 최종량은 두 변수의 곱이라 비선형일 수 있다.
