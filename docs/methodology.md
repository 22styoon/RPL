# 실제 사례 모형의 계산 범위

1. 구로구 2024년 행정처리 대상량을 고정합니다.
2. A는 같은 연도 관측 선별률을 사용합니다. B는 전년 비율을 목표로, C/D는 외생 선별률을 적용합니다.
3. 선별 회수량에 가정 재처리 수율을 곱해 예상 재생원료량을 계산합니다.
4. 선별 잔재 + 가정 재처리 손실 + 예상 재생원료량 = 처리대상량을 검증합니다.
5. 공공예산에 대안별 배율을 적용하고 추가 신규 투자만 연간화합니다.
6. A의 가정 적용 전환비율 이상을 유지하는 등록 대안 중 비교 포함비용이 작은 대안을 선택합니다. 사용자의 추가 목표가 더 높으면 그 목표를 적용합니다.
7. 연간 용량이 제공되면 초과 대안을 제외합니다. 미확인은 별도 표시하며 전체 제약 검증으로 간주하지 않습니다.

설비 투자 연간화는 K×r/[1−(1+r)^(-n)]입니다. 할인율이 0이면 K/n을 사용합니다. K는 기존 투자 총액이 아니라 대안의 추가 신규 투자 가정입니다.

기존 프로젝트 설계의 최종 목표는 총사회적 실물비용 최소화입니다. 현재 실제 사례는 그중 관측 가능한 처리 흐름과 공개 예산부터 구현한 단계입니다. 비용 합계 범위·제약이 불완전하므로 유한 시나리오의 조건부 비교로 제한합니다.
