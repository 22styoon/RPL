# 조건부 정책 실험 방법론

## 1. KOSIS 지역별 4품목 모형

선택 지역·2024년의 대응 4품목 발생량 W_i와 물질재활용 처리량 M_i를 고정 기준선으로 사용합니다. 품목은 폐지류·폐합성수지류·폐금속류·폐유리류이며 영농폐비닐·복합제품 재질은 제외합니다. 전국과 17개 시도를 합산하지 않습니다.

KOSIS 물질재활용 처리량은 최종 재생원료 생산량이 아닙니다. 관측 처리비율 q_i=M_i/W_i를 수거율·선별률로 임의 분해하지 않습니다.

정책 p의 도입비중 a와 처리비율 변화 g_p, 최종수율 변화 h_p를 적용합니다.

```text
q(i,p) = clip(q(i,A) + a × g(p), 0, 1)
y(i,p) = clip(y(i,A) + a × h(p), 0, 1)
M(i,p) = W(i) × q(i,p)
R(i,p) = M(i,p) × y(i,p)
```

g와 h는 절대 비율 변화입니다. 화면의 +3%p는 설정 파일에서 0.03입니다. 품목별 y(i,A)와 정책효과는 D등급 외생 가정입니다. 경계에서 clip을 적용하면 그 사실을 물질수지 표에 표시합니다.

발생량 = 예상 최종 재생원료 + 물질재활용 외 경로 + 가정 재생공정 손실입니다. 물질재활용 외 경로는 에너지회수·소각·매립 등의 구분을 반사실 상황에서 확정하지 않은 묶음입니다. 이를 모두 매립량·선별 잔재라고 부르지 않습니다. 원표의 최대 약 0.4톤 반올림 차이는 관측 수지 차이 열에 보존합니다.

A의 처리비율은 관측값으로 고정합니다. 사용자가 기준 수율 자체를 바꾸는 실험과, B/C/D의 수율 변화 실험을 구분합니다. 대안의 수율이 악화돼도 A의 하한은 따라 내려가지 않습니다.

도입비중 탐색은 A와 B/C/D의 25·50·75·100% 적용을 비교합니다. 효과·추가 투자·용량·생산자 추가원가와 비용 배율을 선형 보간하는 것도 가정입니다. 13개 유한 후보의 탐색이며 연속 투자·시설 입지 최적화가 아닙니다. 적용 비중은 실제 가구·지역을 나누지 않는 집계모형의 효과 강도입니다. 처리비율과 수율 변수를 각각 보간하므로 최종량은 두 변수의 곱에 따라 비선형으로 바뀔 수 있습니다.

## 2. 비용 범위

지역별 단가는 KOSIS에 없어 기본값을 모두 미입력으로 둡니다. 관측된 구로구 예산을 지역별 단가로 자동 외삽하지 않습니다.

| 비용 | 계산 기준 |
|---|---|
| 수거·운반 | 발생량 × 수거 단가 × 정책 배율 |
| 물질재활용 처리 | 가정 물질재활용 처리량 × 단가 × 정책 배율 |
| 물질재활용 외 경로 | 해당 경로 물량 × 단가 × 정책 배율 |
| 재생공정 손실 처리 | 물질재활용 처리량과 예상 최종량의 차이 × 단가 |
| 추가 투자 | 추가 신규 투자비의 연간화 |
| 추가 생산자 실물비용 | 발생량 × 추가 실물단가 × 도입비중 |
| 가계 시간비용(선택) | 대상 가구 × 분/주 ×52÷60 × 시간가치 × 정책 시간 배율 |

물질재활용 처리 단가는 재생공정 손실의 외부 처분비를 제외하는 범위로 입력해야 별도 손실 처리 비용과 중복되지 않습니다. 다른 경로의 서로 다른 소각·매립·에너지 비용을 한 단가로 묶는 것 자체가 단순화 가정입니다.

공공지출 가정은 처리 단가 4종과 추가 투자 연간화의 합입니다. 여기에 추가 생산자 실물비용과 선택한 가계 시간비용을 더한 값을 **범위 내 비교비용**으로 표시합니다. 관측 총사회적 비용·순후생은 아닙니다. EPR 분담금·세금·보조금 등 이전지출은 가산하지 않습니다.

4단가가 모두 입력되어야 비용 순위를 산정합니다. 가계비 포함을 선택하면 가구 수·주당 시간도 필요합니다. 미입력을 0으로 대체하지 않으며, 입력된 비용 부분합으로 정책을 선택하지 않습니다. 사용자가 명시적으로 입력한 0원은 미입력과 구분합니다.

투자 연간화는 K×r/[1−(1+r)^(-n)]입니다. r=0이면 K/n입니다. K는 추가 투자 가정이며 기존 투자 총액이 아닙니다.

## 3. 제약과 결과

최종 전환비율의 하한은 A와 사용자 목표 중 큰 값입니다. 같은 지역·4품목 발생량을 모든 대안의 분모로 고정합니다.

물질재활용 단계 용량은 M(i,p)의 합에 적용하며, 전체 발생량이나 최종 산출량과 혼동하지 않습니다. 공공지출 상한은 가계·생산자 비용을 제외한 공공지출 가정에 적용합니다. 용량 미입력은 미확인이고, 예산이 설정됐는데 비용이 없으면 예산 제약은 미평가입니다. 미확인 용량 후보 제외 옵션을 제공합니다.

재생원료 목표·용량·예산 탈락 사유를 각각 기록합니다. 입력 제약을 통과하더라도 정책효과·시설·법규·안전성을 모두 검증한 정책은 아니므로 전체 검증완료는 거짓으로 유지합니다.

목표곡선은 유한 후보의 단계형 하한 외피입니다. 불가능한 구간은 결측으로 두고 선을 연결하지 않습니다. 화면·CSV·ZIP·CLI는 같은 목표 격자와 전환 경계점을 사용합니다.

민감도는 최종수율 70·85·95%, 대안 처리효과의 추가 -2·0·+2%p, 물질처리 단가의 0.8·1.0·1.2배를 각각 적용합니다. A·목표·제약·선택을 다시 계산하며 확률분포나 신뢰구간을 주장하지 않습니다.

## 4. 구로구 시설 모형

구로구는 별도 관측 범위입니다. 처리대상량 13,195톤, 선별량 7,733톤과 공개 수거·선별 예산을 기준으로 대안별 선별률·최종수율·예산 배율·추가투자를 적용합니다. 품목 구성은 미공표이므로 합계 흐름만 다룹니다.

새 시설 대안 추가, 개별 최종수율, 비교 포함비용 상한, 연간 처리대상량 기준 용량, 미확인 용량 제외와 목표곡선을 지원합니다. 이 용량과 비용 단계는 KOSIS 4품목 모형과 다릅니다. 결과는 예산 대리값의 조건부 비교이며 전국 비용 근거가 아닙니다.

## 5. 재현

정책 ZIP에는 현재 설정·지역·연도·원자료 행·원자료 SHA-256·비용 범위·제약·물질수지·목표곡선·민감도를 포함합니다. 결과 CSV의 비율은 % 단위, 내부 설정은 0~1 비율입니다. 구로 시설 ZIP에는 실제 편집한 대안·제약·원자료 출처를 별도로 포함합니다.
