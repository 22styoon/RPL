# 최종 재생원료 실측자료와 2024년 수거정책 근거 조사

조사 기준일은 2026년 11월 22일이며 재현 기록은 11월 23일에 정리했다. 조사한 공개 자료에는 [F 입력 계약](indicator_data_contract.md)을 모두 충족하는 국가·발생연도·재질 관측값이 **0행**이다. 2024년 수거정책의 운영 근거는 5개 지자체에서 확인했지만, 시군구 전체 연간 생활폐기물 성과와 엄격 결합할 수 있는 신규 행은 **0행**이다. 제주·세종 일회용컵 보증금제의 사업 자체 성과 결합 1행은 기존 범위를 유지한다.

## 1. 최종 재생원료 산출량 F

비교하고자 하는 분모 G는 해당 지역에서 해당 역년에 발생한 생활계 건식 대상물질량이다. 분자 F는 그 발생분이 국내외에서 최종 공정을 거쳐 만든 이용 가능한 재생원료의 대상물질량이다. 폐지·폐합성수지·폐금속·폐유리의 공통 분류와 무수 대상물질 기준을 양쪽에 적용한다. 이전 연도 재고와 수입 폐기물의 산출은 해당 국내 발생분에서 제외하고, 국내 발생분이 이후 연도에 처리되거나 해외에서 실제 산출된 경우는 발생연도와 원산지를 확인해 한 번 귀속한다.

### 우선 요청할 자료

1. **한국환경공단 자원순환통계부와 해당 인허가 기관**에 별지 52호 뒷면 ⑦의 **실제 2024년 신고 자료**를 요청한다. 최초 요청 단위는 한 재질의 시설×폐기물코드×재활용방법×제품 규격별 비식별 생산량이다. 수탁·보관·잔재, 허가 유형, 집계단위와 누락률, 중간제품 분리 가능 여부 및 제공 조건을 함께 확인한다. [공단 문의처와 작성 체계](https://www.data.go.kr/data/15164936/fileData.do)
2. **최종 재활용 시설**에서 45호 관리대장, 반입·공정·출고 계근, 전자인계번호의 비식별 키, 품질·수분 측정, 첨가물·오염물·반려·연료·처분량을 요청한다. 2023년 말 이월 재고와 2024년 발생분이 2025년 이후에 처리된 내역을 별도 표시한다. 수입·국내 원산지, 해외 도착시설의 품질합격 최종제품량과 시설 간 중간제품 이동을 추적한다.
3. **2024년 단일 재질·시설 시범**에서 G와 F의 발생 코호트를 연결하고 건조 대상질량과 이중계상 제거를 확인한다. 검증된 시설의 부분 자료는 보고 범위와 미보고량을 명시한다. 같은 범위의 G까지 검증된 행에서만 F 결측 또는 증빙 가능한 구간을 사용할 수 있다.

### 실행 명령

프로젝트 루트에서 Python 가상환경과 기존 공식 통계 캐시를 준비한다. 9개 종합 분석에는 로컬 영국 폐기물 캐시도 필요하다. GIS는 제공 원본을 유지한 채 복제본과 검토한 대응표·파일 해시를 기본 위치인 `data/raw/regional_2024/gis_boundary/source_manifest.json`에 연결한다. [GIS 입력 준비](regional_operating_policy_and_gis_2026-11-22.md#gis-경계-감사)

```powershell
$python = '.\.venv\Scripts\python.exe'
New-Item -ItemType Directory -Path outputs -Force | Out-Null
& $python -m pip install -r requirements-gis.txt
& $python -B scripts/audit_regional_boundaries.py --check-only
& $python -B scripts/audit_regional_gis.py
& $python -B run_statistical_analysis.py
& $python -B -m pytest -q -p no:cacheprovider
& $python -B run_statistical_analysis.py --output-root outputs/repro-1
& $python -B run_statistical_analysis.py --output-root outputs/repro-2
```

월별 코드 감사가 구형 형식이면 저장된 원표와 월별 원문을 유지하고 `scripts/prepare_regional_recycling.py --year 2024`, `scripts/audit_regional_boundaries.py`, `scripts/join_regional_policy.py --year 2024` 순서로 로컬 근거를 재생성한다. 두 출력의 `tables/` CSV와 `figures/` PNG를 상대 경로 기준으로 짝지어 SHA-256을 비교할 수 있다.
